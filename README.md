Get a quick overview of your network connection's health.
Easy to make sense of.
Useful when your connected is unstable and you want to get an idea of what's failing.
Probably not useful for fiber users, for obvious reasons.
No installation.

Linux:
> node netxray.js

Windows PowerShell:
> ./netxray.cmd
